## 二、飞线清单（一共 11 根）

### A. STM32 ↔ M5Stamp（串口链路，3 根）

| # | 从 | 到 | 颜色建议 | 作用 |
|---|---|---|---|---|
| 1 | STM32 **PA10** | M5Stamp **G1** | 蓝 | 桥接发 → STM32 收 |
| 2 | STM32 **PA9** | M5Stamp **G2** | 绿 | STM32 发 → 桥接收 |
| 3 | STM32 **GND** | M5Stamp **GND** | 黑 | ★ 必须共地 |

```

PA10 ●━━━━━━━━━━━━━━━━━━━● G1
PA9  ●━━━━━━━━━━━━━━━━━━━● G2

```

### B. STM32 ↔ SN65HVD230（CAN，3 根）

| # | 从 | 到 | 颜色建议 | 作用 |
|---|---|---|---|---|
| 4 | STM32 **PB9** | SN65HVD230 **CTX** | 橙 | CAN_TX |
| 5 | STM32 **PB8** | SN65HVD230 **CRX** | 白 | CAN_RX |
| 6 | STM32 **GND** | SN65HVD230 **GND** | 黑（可与 #3 共用）| 共地 |
| 7 | STM32 **3V3** | SN65HVD230 **VCC** | 红 | ★ 只能 3.3V |

```

PB9  ●━━━━━━━━━━━━━━━━━● CTX

| # | 从 | 到 | 颜色建议 | 作用 |
|---|---|---|---|---|
| 8 | STM32 **PB6** | OLED **SCL** | 黄 | I2C 时钟 |
| 9 | STM32 **PB7** | OLED **SDA** | 紫 | I2C 数据 |
| 10 | STM32 **GND** | OLED **GND** | 黑（共用）| 共地 |
| 11 | STM32 **3V3** | OLED **VCC** | 红（共用）| ★ 3.3V |

### D. M5Stamp ↔ OLED 屏（第二块，2 根）

| # | 从 | 到 | 颜色建议 | 作用 |
|---|---|---|---|---|
| 12 | M5Stamp **G9** | OLED **SCL** | 黄 | I2C 时钟 |
| 13 | M5Stamp **G8** | OLED **SDA** | 紫 | I2C 数据 |
| 14 | M5Stamp **GND** | OLED **GND** | 黑（共用）| 共地 |
| 15 | M5Stamp **3V3** | OLED **VCC** | 红（共用）| ★ 3.3V |

## 四、M5Stamp-S3Bat DIP 引脚位置

```

        │  [USB Type-C]        │
        │                      │
  左列   │  ┌──────────────┐   │  右列
   (1)  │  │  S3BAT  EXT  │   │  (5VIN)
   (2)  │  │              │   │  (3V3)
   (3)  │  │   M5STAMP    │   │  (BAT)
   (4)  │  │            8 │   │  8
   (5)  │  │  [PWR-BTN] 9 │   │  9  ──► OLED_SCL (G9) ★飞线
   (G)  │  │            10 │   │  10
   (6)  │  │            11 │   │  11
   (7)  │  └──────────────┘   │
        │                      │
        │  [BAT 电池接口]      │
        └──────────────────────┘
             ↑
        左列丝印 1 2 3 4 5 G 6 7
             │ │           │
             │ └─ G2 (串口RX) ★飞线
             └─── G1 (串口TX) ★飞线

        ★ 照片里 M5Stamp 左列丝印: 1 2 3 4 5 G 6 7

## 七、★ 焊前必做：拔 PA9/PA10 跳帽

野火板上 PA9/PA10 通过**跳帽**连着 CH340（USB 转串口芯片）。

```
PA9  ──┬── 跳帽 ── CH340 RXD
       └── 排针 (飞线这里)
PA10 ──┬── 跳帽 ── CH340 TXD
       └── 排针 (飞线这里)
```

**不拔跳帽的后果：CH340 的输出会和 M5Stamp 的输出对着顶，两边都收不到数据，还可能损坏芯片。**

**做法：把 PA9/PA10 附近那两个小跳帽拔掉。** 板子上丝印可能是 `RXD` / `TXD` / `PA9` / `PA10`。

> 拔了跳帽后 USB 转串口口不能烧录了 —— 但你有 ST-Link，烧录走 SWD，完全不受影响。

## 八、焊后必做：万用表测短路

**上电前用通断档逐项确认（这些都应该"不通"）：**

```
□ PB9  和 PB8   之间        不应通
□ PA9  和 PA10  之间        不应通
□ PB6  和 PB7   之间        不应通
□ G9   和 G8    之间        不应通
□ 任一信号线 和 GND         不应通
□ 任一信号线 和 3V3         不应通
□ 3V3  和 GND               不应通  ★ 这个通了会烧板子
```

**这些应该"通"：**

```
□ STM32 GND ↔ M5Stamp GND     应通
□ STM32 GND ↔ SN65HVD230 GND  应通
□ STM32 GND ↔ OLED GND        应通
```

**焊完打热熔胶做应力释放**，不然一动就断。

## 九、分步上电（不要一次全接）

| 步骤 | 接什么 | 验证 |
|---|---|---|
| 1 | 只接 STM32 的 OLED（PB6/PB7/3V3/GND）| 屏幕出开机画面 `OLED OK` |
| 2 | 再接 M5Stamp 的 OLED（G9/G8/3V3/GND）| 屏幕出开机画面 |
| 3 | 接串口 3 根（PA10/G1、PA9/G2、GND）| 桥接日志出现 `STM32 yaw=` |
| 4 | 接 CAN 4 根（PB9/CTX、PB8/CRX、3V3/VCC、GND）| 桥接日志 `T=` 变室温 |
| 5 | 接电机 CANH/CANL + 120Ω | 主机敲 `1`，电机摆动 |
