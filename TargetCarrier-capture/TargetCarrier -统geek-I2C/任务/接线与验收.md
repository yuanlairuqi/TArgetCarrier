# 接线与硬件验收

两组通信都是“一块普通 ESP32-S3 接一块对应 STM32”，x轴与靶车分别接线。已按照片及[官方引脚表](https://docs.m5stack.com/en/core/Stamp-S3Bat)确认为Stamp-S3Bat，侧边GPIO1～11；GPIO12～16旧分配已撤回。GPIO16在BTB细间距口，不使用该口。下表不用于 GEEK；GEEK 的显示屏和 USB/无线连接保留原状。参考 STM32 为现有 F103，后续换芯片必须移植寄存器/DMA/中断/时钟部分。

## SPI 副本

| 信号 | ESP32-S3 主机 | STM32F103 从机 | 方向 |
|---|---|---|---|
| SCK | GPIO3 | PA5 / SPI1_SCK | ESP → STM |
| MOSI | GPIO4 | PA7 / SPI1_MOSI | ESP → STM |
| MISO | GPIO5 | PA6 / SPI1_MISO | STM → ESP |
| CS/NSS | GPIO11 | PA4 / SPI1_NSS、EXTI4 | ESP → STM，低有效 |
| GND | GND | GND | 共地 |

建议初始配置为 Mode 0、MSB first、1 MHz；每次 CS 拉低传完整 128 字节，全双工。ESP 使用 SPI2_HOST + 自动 DMA；STM 使用 SPI1 + DMA1 通道2/3，NSS 上升沿确认结束并重装 DMA。无独立 READY 线。ESP 最小2ms间隔轮询，以SA传输应答确认STM队列接收；未确认的下行槽在100ms内重发，重复槽去重，超时丢弃并计数。短事务不消费 STM 待发槽；STM 应答机会与状态槽交替调度。2ms是配置值，DMA/IRQ重装和实际稳定余量须硬件验证。STM32duino 使用 attachInterrupt 注册 PA4 回调，避免重复定义其 EXTI4 中断入口；HAL 工程使用共享驱动入口。

## I²C 副本

| 信号 | ESP32-S3 主机 | STM32F103 从机 | 方向 |
|---|---|---|---|
| SDA | GPIO4 | PB11 / I2C2_SDA | 双向，开漏 |
| SCL | GPIO5 | PB10 / I2C2_SCL | 主机时钟 |
| DRDY | GPIO11 | PB1 | STM → ESP，待发邮箱有效时为高 |
| GND | GND | GND | 共地 |

7 位地址 0x42，建议初始 400 kHz。ESP 使用 **I2C_NUM_1**，保留 OLED 的 I2C_NUM_0；STM 使用 I2C2 EV/ER 中断，未占 DMA。写 128 字节下行、读 128 字节上行、另写 12 字节 AK/2 确认，是三个事务。读操作本身不消费 STM 邮箱；确认中的 seq 与槽 CRC 都匹配才消费。两组各自独立总线可以使用相同地址；若改为同一根总线，必须重新分配地址、DRDY 和调度，当前没有实现该拓扑。

SDA/SCL 需外接上拉到 3.3 V；2.2–4.7 kΩ 仅为短线起始建议，实际按线电容、上升时间和器件灌电流选定。未启用依赖 ESP 弱内部上拉的方案。

## 完整ESP侧边引脚预算

| 侧边GPIO | SPI版用途 | I²C版用途 |
|---|---|---|
| G1、G2 | 原x轴限位输入 | 原x轴限位输入 |
| G3 | SPI SCK | 预留 |
| G4 | SPI MOSI | I²C SDA |
| G5 | SPI MISO | I²C SCL |
| G6、G7 | 原x轴PUL/DIR采集 | 原x轴PUL/DIR采集 |
| G8、G9 | 原OLED SDA/SCL | 原OLED SDA/SCL |
| G10 | 用户输出信号（保留） | 用户输出信号（保留） |
| G11 | SPI CS | DRDY |

靶车沿用相同总线配置，并保留G8/G9 OLED；未使用的x轴专用脚仍预留。SPI版连同用户G10输出及保留功能正好用完11个侧边GPIO，不再有可自由追加的侧边信号脚。板载M5PM1的内部G47/G48不作外部通信脚。

## 资源边界

- 两端均按 3.3 V 逻辑和共地接线；电源连接需依据实际板卡供电方式确认，表内未要求把两块板的 3V3 输出直接相连。
- SPI/I²C 接口替换原 STM↔ESP UART 数据线，旧 TX/RX 不再承担该链路。I²C2 的 PB10/PB11 与原 x轴 USART3 复用，本版不再初始化 USART3。
- GPIO1/2 限位、现有 OLED、STM32 PUL/DIR、CAN 和 GEEK 屏幕保持原业务用途。本版SPI使用G3/G4/G5/G11，I²C使用G4/G5/G11；G10专门保留给用户输出，避开上述已有占用；配置加入可用范围、保留脚与重复选脚编译检查。其他历史分支不作同样承诺。
- STM 时钟假设 HCLK/PCLK1/PCLK2=72/36/72 MHz。SPI DMA通道2/3及EXTI4，I²C 的 PB1 和 I2C2 EV/ER 是平台适配层资源。使用串口调试并不意味着业务仍经 UART。
- GPIO编号对应用户照片S3BAT的侧边丝印，并由官方引脚资料核对；已焊接洞洞板背面连线、未显示的器件占用、通断、线长和电磁环境仍未实测。照片中W/WAKE属于电源管理唤醒，不作普通ESP GPIO使用。

## 后续验收清单（本次均未进行）

1. 先断开电机动力，确认板卡型号、管脚引出、共地和 3.3 V 电平；I²C 测上拉与上升时间。
2. 用已授权的方式烧录相同接口的一对固件，ESP-NOW 使用真实配对配置重新构建；不能混用 SPI、I²C、历史 UART 固件。
3. 逻辑分析仪检查 SPI Mode0/CS/128字节及重传确认，或 I²C 地址/ACK/DRDY/AK2；确认 DMA/IRQ 无持续溢出。
4. 测双方重启、断线、短事务、总线繁忙、CRC 错误、重复读、重连、STOP优先和旧报文拒绝；验证断线不会自行恢复运动。
5. 空载核对参数读写、状态回传和上位机连接状态，记录吞吐量、丢包、RTT和RTOS栈余量；这些才是硬件测量。
6. 另获电机测试授权后再验证实际停机延时、限位和运动行为。此链路不是独立硬件紧急断电回路。
