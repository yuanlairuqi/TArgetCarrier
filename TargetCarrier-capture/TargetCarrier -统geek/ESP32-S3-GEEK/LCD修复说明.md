# LCD 显示修复 · 2026-10-22

根据用户实拍发现倒置文字和大面积彩色未刷新区域。旧代码以 MADCTL=0x70 开启横向扫描，却使用135×240画布、X偏移52/Y偏移40，将行末地址写到279；横向扫描的行地址范围与该窗口不匹配。

修复采用官方示例压缩包自带 TFT_eSPI/ST7789_Rotation.h 的 landscape rotation 3 组合：MADCTL=0xA0、240×135、X偏移40/Y偏移52。完整刷新列40–279、行52–186，写入64800字节。默认方向按用户照片中USB插头朝右的摆放选择，最终方向仍需实屏复核。

重新布局为横屏状态页，使用清楚的5×7无衬线字形；显示USB心跳、节点、信道、未配对/从机状态、指令速度及STM输出确认。未配对显示PAIRING REQUIRED。背光保持关闭，直至首帧全部写完。

修改文件为main/panel.c、main/main.c，新增main/font5x7.h。USB/无线/运动协议未修改；未烧录，未执行电机操作。

实际panel.c通过SPI/GPIO主机桩编译和记录测试，检查旋转命令、窗口边界、完整帧长度、四种显示调用、参数限幅、先写屏后点亮背光；软件预览由实际生产帧缓冲转换而来，不是实体屏幕照片。ESP-IDF 6.1最终编译通过。

artifacts内BIN/ELF/bootloader/分区/sdkconfig/日志/哈希已更新。继续使用之前三文件烧录命令，文件路径和地址不变。当前仍是未配对版本。实体显示方向、SPI完整性及整机链路仍需重新烧录后确认。
